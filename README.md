# Vitwar — نسخة فرعين + مزامنة لحظية + تليجرام

⚠️ **قبل ما تشغل حاجة، اقرأ ملف `SETUP.md`** — فيه خطوات لازم تعملها مرة واحدة
بس (ربط Firebase مجاني + بوت تليجرام) عشان الموقع يشتغل صح لكل الناس مش بس
جهازك. من غيرها الموقع هيفتح ويشتغل شكليًا بس التعديلات هتفضل محلية على
جهازك بس.

## اللي في النسخة دي

### 1) فرعين منفصلين تمامًا
- شاشة "اختيار الفرع" في أول الموقع للعميل: **تجمع اول** و **تجمع خامس**، وتحت كل
  واحد مكانه مكتوب.
- كل فرع له منيو وأوردرات وحالة (مفتوح/مغلق/مشغول) منفصلة تمامًا عن التاني.
- لوحة الأدمن كمان فيها اختيار فرع الأول، وبعدين تسجيل دخول خاص بيه:
  - تجمع اول: يوزر `vitwar1` / باسورد `mohand@vitwar`
  - تجمع خامس: يوزر `vitwar5` / باسورد `mohand@vitwar`

### 2) كل حاجة بتتزامن لحظيًا لكل الناس
لما تحدث المنيو أو تغير حالة الفرع من لوحة الأدمن، التحديث بيظهر فورًا لكل
عميل فاتح الموقع من أي جهاز أو متصفح — مش بس اللي فاتح نفس الجهاز. الطلبات
كمان بتوصل الأدمن من أي مكان لحظيًا. (محتاج إعداد Firebase من `SETUP.md`).

### 3) حالة الفرع: مفتوح / مغلق / مشغول
من لوحة الأدمن، زرار واحد يغير حالة الفرع:
- 🟢 **مفتوح**: العملاء يطلبوا عادي زي دلوقتي.
- 🟠 **مشغول**: العميل يقدر يطلب، بس بيتقاله إن الأوردر اتسجل وهيتنفذ لما الفرع
  يرجع متاح.
- 🔴 **مغلق**: مينفعش العميل يكمل طلب؛ بيظهرله تنبيه أحمر واضح مكتوب فيه
  "الفرع مقفول دلوقتي" مع صوت خفيف تلقائي.

### 4) إشعار تليجرام لحظي لكل أوردر
أي أوردر جديد (من أي فرع) بيتبعت رسالة فيه على بوت تليجرام بتاعك أوتوماتيك،
فيها كل تفاصيل الأوردر (رقم الكود، الأصناف، الاختيارات، الإجمالي، طريقة
الدفع...). كده لو مش موجود جنب الجهاز، الأوردر لسه بيوصلك.

### 5) كود لكل أوردر يبدأ من #184
كل عميل بعد ما يأكد طلبه بيشوف كود الأوردر بتاعه (#184 وبعدين #185 وهكذا)،
والرقم مشترك بين الفرعين ومحفوظ بشكل دائم.

### 6) طريقة الدفع بقت أزرار
بدل خانة كتابة حرة، العميل بيختار بزرار: **كاش** أو **انستاباي**.

### 7) مجموعتين اختيارات للصنف الواحد
من فورم الصنف في لوحة الأدمن:
- **مجموعة اختيارات بسعر** (زي الأول): كل اختيار ليه سعره الخاص.
- **مجموعة اختيارات من غير سعر** (جديد): مثلاً "طبق" أو "ساندوتش" — اختيار
  بس من غير ما يأثر على السعر خالص.

### 8) تصميم اللمس بدل تظليل المتصفح الأزرق
كل الأزرار دلوقتي بتاخد تأثير ضغطة (تصغير خفيف) بدل الهايلايت الأزرق
الافتراضي بتاع المتصفح، ورسايل التنبيه/التأكيد بقت بشكل الموقع (زجاجي وردي)
بدل نافذة `alert`/`confirm` بتاعت المتصفح.

## هيكل المشروع
```
index.html          -> صفحة العميل (اختيار فرع + منيو + سلة + إتمام طلب)
admin.html           -> لوحة الأدمن (اختيار فرع + دخول + طلبات/أصناف/إعدادات)
css/style.css          -> كل التصميم
js/firebase-config.js    -> اكتب هنا بيانات مشروع Firebase بتاعك (SETUP.md)
js/firebase-init.js       -> تشغيل Firebase + بيانات الفروع الثابتة
js/store.js                 -> كل عمليات القراءة/الكتابة (منيو، حالة، أوردرات، عداد الكود)
js/telegram.js                -> إرسال إشعار الأوردر لبوت تليجرام
js/toast.js                     -> تنبيهات/تأكيدات بشكل الموقع + الأصوات
js/main.js                        -> منطق صفحة العميل
js/admin.js                         -> منطق لوحة الأدمن
images/                                -> صور المنتجات + اللوجو
SETUP.md          -> خطوات الربط بـ Firebase + بوت التليجرام (مهم جدًا)
```

## تغيير عناوين/أسماء الفروع
افتح `js/firebase-init.js` وعدّل قسم `BRANCHES` (الاسم والعنوان لكل فرع).
