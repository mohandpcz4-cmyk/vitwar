# فولدر الخطوط (fonts)

حط هنا أي من الملفين دول (الاسم لازم يكون بالظبط زي ما هو مكتوب):

- **sold.ttf** → الخط اللي هيتكتب بيه الكلام على شريط "نفذت الكمية / Sold Out"
  اللي بيظهر فوق صورة أي منتج غير متاح. لو الملف موجود هيتستخدم تلقائيًا،
  ولو مش موجود الموقع هيرجع لخط شبيه بخط الآلة الحاسبة بتاعة الآيفون
  (SF Pro) وميحصلش أي خطأ في التصميم.

- **emoji.ttf** → خط الايموجي بتاع كل الموقع (الرموز التعبيرية 😀🔔🛒 إلخ).
  لو الملف موجود هيغيّر شكل الايموجي بس، وميأثرش خالص على خط الكتابة
  العادي (Cairo). لو مش موجود، الايموجي هيفضل بشكله الافتراضي بتاع الجهاز.

مفيش داعي تعدل في أي كود — تحميل الملف في الفولدر ده كفاية.
